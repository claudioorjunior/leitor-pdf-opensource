# Issue: Impressão — diálogo próprio (estilo PDFgear) + spool direto

**Título sugerido:** `feat(print): diálogo de impressão próprio com spool`
**Labels:** `enhancement`, `print`, `ux`
**Prioridade:** média — depois da navegação (missão atualizada inclui imprimir)

---

## Resumo

Adicionar **Imprimir** ao Tsuro como **diálogo próprio estilo PDFgear**: modal em iced
com preview, impressora, intervalo, cópias e orientação; o app monta um **PDF de
impressão** (~200 DPI via `pdf-writer`) com a seleção assada e faz **spool direto**
para a impressora nas 3 plataformas (crate `printers`: CUPS no mac/Linux, winspool
no Windows). Rota de fuga "Abrir PDF" (temporário no visualizador padrão).

**Decisão registrada (2026-09-08)**: missão atualizada para "ler, anotar, marcar,
**imprimir**" (AGENTS.md + README.md já alterados).
**Writer (2026-09-09)**: a issue original citava `printpdf`; usa-se `pdf-writer` 0.15
+ `miniz_oxide` 0.8 (Flate RGB, MediaBox em pontos).
**Diálogo próprio (2026-09-10)**: spec aprovada em
`docs/superpowers/specs/2026-09-10-print-dialog-design.md`. Caminhos anteriores
(folha nativa NSPrintPanel via objc2; só-abrir-no-Preview) foram substituídos; deps
objc2 removidas. Dep nova `printers` 2.x aprovada com o design.

## Motivação

- Usuários esperam imprimir contrato/artigo do leitor, escolhendo impressora e
  páginas sem sair do app.
- iced 0.13 **não tem** diálogo de impressão; o Tsuro desenha o seu e usa o spooler
  do SO para entregar o job.
- O Tsuro já renderiza páginas em qualquer escala (`engine.render(page, scale)`) —
  a impressão é um re-render em DPI alto + empacotar em PDF; Pdfium intacto.

## Princípios (não negociáveis)

1. Engine Pdfium inalterado — reusa `render(page, scale)` com `Scale` de ~200 DPI.
2. Dependências novas (`pdf-writer`, `miniz_oxide`, `printers`); pedir aprovação
   antes de adicionar (regra AGENTS "Ask first: new dependencies").
3. Seleção assada no PDF (intervalo/cópias/orientação) — funciona mesmo onde o
   spooler ignora opções.
4. V1 essencial: impressora, intervalo (Todas/Atual/De–Até), cópias (1–99),
   orientação, preview. Fora: papel, duplex, cor/P&B, salvar-como-PDF.
5. PDF de impressão = páginas no tamanho da folha real (MediaBox), como qualquer
   leitor faz.
6. Falha nunca descarrega o documento: erro em banner no diálogo, sem
   `Session::Failed`.

## Estado atual vs alvo

| Aspecto | Hoje | Alvo |
|---|---|---|
| Imprimir | Não existe | Menu ⋯ → **Imprimir** abre o modal próprio |
| Seleção | — | Impressora (default pré-selecionada), intervalo, cópias, orientação |
| Preview | — | Thumb do cache + "X de Y" dentro do intervalo |
| DPI | Render em escala de tela | Re-render ~200 DPI (Scale::from_factor) |
| Saída | — | `printers` → spool direto (CUPS/winspool); "Abrir PDF" como fuga |
| Thread | — | Lista, render e spool fora da UI (`spawn_blocking`) |

## Wireframe (fluxo)

```text
⋯ → Imprimir
      │
      ▼
modal: lista impressoras (spawn_blocking) + preview do intervalo
      │
      ▼
[Imprimir] → render @ ~200 DPI → PDF assado (pdf-writer, XObject compartilhado)
      │
      ▼
spool na impressora → fecha + "Enviado para {nome} (job {id})"
      │
 (falha) → banner no diálogo, documento intacto
```

## Implementação

1. **Seleção + montagem** (`print.rs`): `PrintRange`/`PrintOrientation`/`PrintSelection`
   puros; `print_selection_pdf` filtra, gira e repete; cada página única vira 1 Image
   XObject compartilhado pelas cópias. Testável sem IO.
2. **Spool** (`spool.rs`): fronteira com o crate `printers` (`list_printers`,
   `spool_pdf` → job id); tipos próprios; stub em `cfg(test)`.
3. **Diálogo** (`session.rs` + `view.rs`): `Ready.print_dialog: Option<PrintDialog>`
   + mensagens (`OpenPrintDialog`, `PrintSubmit`, `PrintSubmitted { doc_gen, .. }`,
   `PrintOpenPdf`, …); modal iced com preview + controles + rodapé
   (Imprimir/Abrir PDF/Cancelar); guarda `doc_gen`; Esc fecha (ignorado enviando).
4. **Limpeza**: remover caminho NSPrintPanel + deps objc2; temporário vira "Abrir PDF".

## Testes

- Unit (sem IO): intervalo, expansão de cópias + teto, rotação/orientação, validação
  1-based, mapeamento CUPS/fakes.
- Sessão (stub de spool): abrir/fechar, seleção default, submit inválido/sem
  impressora, busy, ok/erro/stale, hatch Abrir PDF, preview por intervalo, Esc.
- Fixture: `guia-folio.pdf` — seleção De–Até × 2 cópias confere contagem via parser.
- Suíte completa `cargo test -p tsuro` verde, sem impressora instalada.

## Smoke manual (critério de pronto = papel correto, 1× por SO)

Listar impressoras, imprimir Todas, intervalo De–Até, 2 cópias, forçar paisagem,
sem impressora (banner + Abrir PDF), cancelar diálogo.

## Limitações conhecidas

- Windows winspool RAW só imprime PDF em impressora com suporte nativo a PDF;
  demais casos falham com erro visível + rota "Abrir PDF" (v1).

## Comportamento do modal

- O preview agenda o thumb da página atual mesmo de painel Páginas fechado.
- Setas do teclado paginam o preview com o modal aberto (não o documento).
- Clique no fundo escurecido fecha o diálogo (ignorado durante o envio).
- Setas do teclado navegam o documento mesmo com o modal aberto (wart conhecido).

## Definition of Done

Issue fechada quando o diálogo próprio faz spool com papel correto nas 3 plataformas
e o smoke acima passa 1× em cada SO.
